## 🎯 Главная идея и концепция проекта

> **«Талант есть у каждого человека, но он может проявляться по-разному. Важно не только иметь способности, но и замечать их, развивать и использовать во благо себе и другим.»**

Проект создан для ученика **8 класса** с образовательной и исследовательской направленностью. Сайт не выглядит как детская игра или развлекательный квиз: он спроектирован как **современная научно-познавательная платформа**, где интерактивные элементы дополняют содержание, стимулируют рефлексию и профориентацию.

Вторая часть темы связывает понятия **«гений»** и **«герой»**: настоящий героизм — это не суперсилы из комиксов, а готовность применить свои уникальные способности ради помощи обществу (врачи, спасатели, учителя, инженеры, программисты, волонтёры и неравнодушные школьники).

## 🌟 Ключевые возможности и разделы

1. **Главная (Hero) и 3D-модель «Сфера Потенциала»**:
   - Интерактивная 3D-сцена на **Three.js** с икосаэдрическим светящимся ядром, внешним каркасом и 10 световыми узлами, символизирующими виды таланта.
   - Вращение мышью и тач-жестами, инерция, режимы авто-вращения, переключение каркаса и HUD-индикатор фокусного узла.
2. **Что такое талант? (Теория)**:
   - Разграничение понятий: *талант*, *способность*, *навык*.
   - Почему талант не всегда заметен в детстве (скрытые задатки, отсутствие среды, нейробиологическое созревание).
   - Сравнительная таблица: **Талант | Способность | Навык** с шестью критериями анализа.
3. **Как формируется талант? (Механизм)**:
   - Пошаговый пайплайн: **Интерес → Практика → Ошибки → Опыт → Развитие → Результат**.
4. **10 видов талантов**:
   - Карточки с подробным описанием: *Интеллектуальный, Творческий, Технический, Музыкальный, Спортивный, Коммуникативный, Лидерский, Социальный, Литературный, Научно-исследовательский*.
   - Живой поиск в реальном времени и фильтрация по категориям (STEM, Искусство, Общество, Спорт).
5. **Талантливые люди (Примеры)**:
   - Примеры синергии дара и титанического труда: *Леонардо да Винчи, Моцарт, Эйнштейн, Стив Джобс, Лионель Месси*.
6. **Интерактивный тест: «Определи свои сильные стороны»**:
   - Серьёзный психологический опросник из **15 вопросов** с 4 вариантами ответов.
   - Оценка по 8 направлениям, расчёт процентов, выявление ведущей пары способностей.
   - Рекомендации по развитию для 8 класса, сохранение в `localStorage`, копирование отчёта и печать на А4.
7. **Таланты и профессии (Профориентация)**:
   - Базовая матрица профессий.
   - **Интерактивный конструктор синергии**: выбор двух талантов показывает профессии будущего на их стыке.
8. **Как развивать свой талант?**:
   - 8 научно обоснованных принципов развития.
   - Чек-лист полезных привычек с сохранением состояния.
9. **Мифы и факты о таланте**:
   - Интерактивный аккордеон с научным разоблачением стереотипов (нейропластичность, преодоление ошибок, поздний старт).
10. **Путь от интереса к мастерству**:
    - Временная шкала из 7 стадий становления личности.
11. **Талант и героизм**:
    - Повседневный героизм специалистов и школьников во благо общества.
12. **Талант и общество**:
    - Симфония способностей и социальная гармония.
13. **Если я ещё не нашёл свой талант?**:
    - Мотивационная психологическая поддержка подростка 14–15 лет.
14. **Мой пример (Блок автора)**:
    - Личный опыт ученика 8 класса: синтез тяги к IT и творческого чувства слова.
    - Встроенная возможность редактировать имя и текст автора прямо на сайте.

## 🛠 Технологический стек

* **HTML5**: Семантическая разметка, доступность (`aria-*`), микроразметка Schema.org JSON-LD, OpenGraph & Twitter Card SEO.
* **CSS3**: CSS Custom Variables (Design Tokens), Flexbox, CSS Grid, Glassmorphism, адаптивность (Mobile, Tablet, Desktop), Print CSS (`@media print`).
* **JavaScript (ES6+)**: Чистый модульный код без внешних фреймворков и бэкенда, Three.js r128 для 3D, LocalStorage API, Clipboard API.
* **Векторная графика (SVG)**: Премиальные иконки и векторный фавикон `favicon.svg`.

## 🚀 Запуск проекта локально

Проект полностью автономен и не требует установки Node.js или сервера.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/type-0713/BSB.git
   cd BSB
   ```
2. Откройте файл `index.html` в любом браузере:
   * **Windows**: двойной клик на `index.html` или в терминале `start index.html`.
   * **macOS**: `open index.html`.
   * **Linux**: `xdg-open index.html`.
